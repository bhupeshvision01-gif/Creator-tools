# Creator Profit Lab

A professional calculator website for creators with 90+ free online calculators.

## Website

Live at: https://yourusername.github.io/creatorprofitlab (after deployment)

## Features
- 90+ Calculators (YouTube Earnings, BMI, ROI, CPM, etc.)
- Creator Economy, Finance, Health, Math, Business & Lifestyle tools
- Search, Categories, Blog, Privacy Policy
- Fully responsive & modern UI

## How to Run Locally
```bash
npm install
npm run dev
```

## Deployment to GitHub Pages
This repository is configured to automatically deploy to GitHub Pages when you push to `main`.

Just push your code — the website will build and deploy automatically.

## Calculators Included
- Creator Economy (YouTube, Instagram, TikTok, Brand Deals)
- Finance & Money (EMI, SIP, Compound Interest, GST)
- Health & Fitness (BMI, BMR, Heart Rate, Water Intake)
- Math & Science (Percentage, Temperature, Scientific)
- Business Tools (ROI, Break-even, Price Comparison)
- Lifestyle (Carpet Calculator, Trip Cost, Currency Converter)
